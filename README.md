# Landing Page — Oráculo / Tarô

Projeto inspirado na estrutura visual da página de referência enviada pelo cliente.

## Arquivos
- index.html
- css/style.css
- js/script.js

## Configurar WhatsApp
Abra `js/script.js` e altere:

const WHATSAPP_NUMBER = "5511999999999";

Use o número com código do país e DDD, sem espaços, parênteses ou hífen.

Exemplo:
5511998765432

## Personalização
Os textos, nomes dos serviços, cores e tipografia podem ser alterados diretamente no HTML/CSS.

A página não possui checkout. Os CTAs levam diretamente ao WhatsApp.
